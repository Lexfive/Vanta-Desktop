<h1 align="center">Vanta</h1>
<p align="center"><b>Workspace desktop para o WhatsApp Web, feito para equipes.</b></p>
<p align="center"><a href="https://apps.lexfive.com/vanta/"><img src="https://img.shields.io/badge/Baixar%20para%20Windows-000000?style=for-the-badge&logo=windows&logoColor=25d366" alt="Baixar para Windows"></a></p>

Abre o WhatsApp Web oficial numa janela nativa leve e coloca ao redor dele o que uma equipe de atendimento precisa.

- **Várias contas** abertas ao mesmo tempo.
- **Bloqueio por PIN** e proteção contra captura de tela.
- **Respostas prontas**, atalhos de conversas (Ctrl+K) e discador direto.
- **Atualizações automáticas**; instalador sem exigir administrador e pacote MSI para GPO/Intune.

Windows 10/11 (64 bits) · gratuito · código fechado. Termos de uso em [apps.lexfive.com/vanta/termos](https://apps.lexfive.com/vanta/termos/).
